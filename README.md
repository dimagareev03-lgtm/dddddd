# КастаДент — сайт стоматологии

Одностраничный сайт стоматологической клиники «КастаДент» (Краснодар).
Самодостаточный `index.html`: вся разметка, стили и скрипты — внутри одного файла.

## Что внутри

- Тёмно-бирюзовая тема (glassmorphism) со светлой темой по `prefers-color-scheme`.
- Hero с анимацией и **3D-моделью зуба** (three.js); при отсутствии WebGL —
  запасной эмодзи 🦷.
- Секции: Услуги, Отзывы, Акции, Наша команда, Контакты (форма записи),
  схема проезда со ссылками на Яндекс.Карты.
- Форма записи формирует письмо (`mailto:`) на почту клиники — отправки на сервер
  нет, это фронтенд-заглушка.
- Адаптивная вёрстка, анимации учитывают `prefers-reduced-motion`.

## Запуск

Достаточно открыть `index.html` в браузере. Удобнее — через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Зависимости (с CDN)

- Google Fonts — шрифты Unbounded и Onest.
- three.js (r128) с cdnjs — для 3D-зуба.

Нужен доступ в интернет, иначе шрифты заменятся системными, а вместо 3D-зуба
покажется эмодзи.

## Хостинг

Статика — подойдёт любой статический хостинг (GitHub Pages, Netlify и т.п.): достаточно
отдать `index.html`.

> Контакты, адрес, телефон и состав команды — реальные данные клиники; при
> необходимости правятся прямо в `index.html`.
