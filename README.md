# Кастадент — сайт стоматологической клиники

Статичный многостраничный сайт стоматологии «Кастадент» на чистом HTML, CSS и
JavaScript. Без сборки и зависимостей — открывается прямо в браузере и легко
хостится (например, на GitHub Pages).

## Страницы

- `index.html` — Главная (hero, преимущества, услуги, призыв к записи)
- `services.html` — Услуги (направления клиники)
- `doctors.html` — Врачи (специалисты)
- `prices.html` — Цены (прайс-лист по категориям)
- `contacts.html` — Контакты и форма записи на приём

## Структура

```
index.html, services.html, doctors.html, prices.html, contacts.html
css/style.css   — все стили (CSS-переменные, адаптив, компоненты)
js/main.js      — бургер-меню, подсветка активного пункта, валидация формы
```

## Запуск

Можно просто открыть `index.html` в браузере. Для корректной работы ссылок
удобнее поднять локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Особенности

- Адаптивная вёрстка (корректно от 320px), мобильное меню-бургер.
- Иконки и логотип — инлайновый SVG, без бинарных файлов.
- Форма записи на приём с валидацией на фронтенде (без бэкенда — показывает
  сообщение об успешной отправке; реальная отправка требует серверной части).

> Контактные данные, цены и имена врачей — демонстрационные, замените на реальные.
